Google Drive 연결 설정

처음 한 번 Google Cloud에서 웹 OAuth 클라이언트 ID를 만드세요.

  1. Google Cloud Console에서 프로젝트를 선택하거나 생성합니다.
  2. Google Drive API를 사용 설정합니다.
  3. Google Auth Platform에서 앱 이름을 Watchparty로 설정하고, 테스트 사용자에 본인 Google 계정을 추가합니다.
  4. 데이터 액세스 범위에 https://www.googleapis.com/auth/drive.file을 추가합니다.
  5. 클라이언트 → 웹 애플리케이션을 만들고 승인된 JavaScript 원본에 https://unihit.github.io를 등록합니다.

클라이언트 보안 비밀은 필요하지 않습니다. 앱이 만든 watchparty 파일만 접근하며, 개인 파일을 공개하지 않습니다.
